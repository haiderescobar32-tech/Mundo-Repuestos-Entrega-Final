# MUNDO REPUESTOS
### Sistema de gestión y tienda virtual de repuestos automotrices

**Descripción del proyecto**

Mundo Repuestos es una aplicación web desarrollada para facilitar la consulta, comercialización y administración de repuestos automotrices.

**Tecnologías utilizadas**
- Java
- Spring Boot
- MySQL
- HTML5
- CSS3
- JavaScript
- Maven

**Funcionalidades principales**
- Catálogo de repuestos.
- Búsqueda y consulta de productos.
- Filtrado por categorías y marcas.
- Búsqueda de repuestos por vehículo.
- Carrito de compras.
- Gestión de pedidos.
- Administración de productos.
- Control de inventario.
- Gestión de compatibilidad entre repuestos y vehículos.

**Base de datos**

El proyecto incluye el archivo `repuestos.sql`, que contiene la estructura de la base de datos y datos de demostración.

**Ejecución del proyecto**

1. Instalar Java y MySQL.
2. Crear o importar la base de datos utilizando `repuestos.sql`.
3. Configurar las credenciales de conexión a MySQL en `application.properties`.
4. Abrir el proyecto con Visual Studio Code o un entorno compatible con Maven.
5. Ejecutar la aplicación Spring Boot.
6. Abrir la aplicación desde el navegador mediante `http://localhost:8080`.
